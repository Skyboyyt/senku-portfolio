Behind the project: SupportFlow AI

The problem

Small support teams answer the same questions all day while the conversations that need judgement wait in the same queue. Most chatbots either answer everything with false confidence or are too locked down to help.

The build

A Next.js web app and a Fastify API on PostgreSQL, with retrieval over each workspace’s published articles, a provider-agnostic AI layer, signed Stripe webhooks and a 20 KB Shadow DOM widget. Tests try to cross between workspaces and break the AI, and the end-to-end suite runs a full journey from sign-up to a realtime handoff.

The scope

Live on Vercel, with the API on Cloudflare Workers and Postgres on Neon, and tested end to end against the live site. The screenshots use a development workspace and a fictional coffee shop. Email delivery isn’t connected, so invitations are shared as links, and AI replies come from Llama 3.3 on Cloudflare Workers AI, using its free daily allowance.

Behind the project: Pulse Grid

The idea

I wanted a small instrument that feels immediate: open it, tap a few steps and hear a groove, then send it to a friend without an account or upload.

The build

A look-ahead scheduler queues notes on the Web Audio clock so timing stays steady while the page is busy. Patterns pack into a compact, validated link format, and the same voice code renders the WAV export offline. Pattern logic is covered by unit tests.

The scope

Beats are kept in the page link and nowhere else; only the colour theme is stored in the browser. It is a sketching tool rather than a full music workstation, so there is no sample import or MIDI yet.

08 / Wallet research

Blacklist.

blacklist-web-eta.vercel.app

Check evidenceResearch before trust

Web3 platform / Full-stack TypeScript

A Web3 anti-scam and project-verification platform I’m building.

Blacklist helps people research crypto projects, wallets, tokens and contracts before they trust them, and gives victims and researchers an evidence-based, accountable way to report, review and contest suspicious activity.

Try the test site (opens in a new tab)Follow the build on GitHub (opens in a new tab)
  • Wallet & transaction researchLook up Ethereum and Solana wallets, tokens and transactions, with readable balances, token holdings and transfer history from live blockchain providers.
  • Reports with image evidenceMembers report scams with screenshots. Every image is checked and re-encoded by an isolated processor that strips hidden data, so staff only ever see a clean copy.
  • Careful moderationStaff sign in with security keys, severe findings need a second reviewer, and the projects involved can respond and appeal. Every decision is recorded.
  • Fairness built inBeing linked to a wallet does not mean being guilty. Findings stay sourced and open to challenge, risk is shown in bands instead of a score, and a low band never means “safe”.

Building the platform end to end

Running on a public test environment with real blockchain data. It is not launched yet: public risk ratings stay off until they are calibrated, and image uploads accept test images only. The recording shows the app’s demo mode, which uses fictional data.

Behind the project: Blacklist

The problem

Crypto scams spread faster than the facts. Blacklist aims to give people one careful place to check a project or wallet before they commit.

How I’m building it

In planned phases, each reviewed before the next: the frontend on sample data first, then the backend foundation and accounts, blockchain research, reports and moderation, the risk engine and admin tools, and image evidence.

What’s next

Launch readiness: an independent security review, a legal review, recovery drills and a production setup, before anyone relies on it for real.
